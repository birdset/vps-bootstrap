# VPS Bootstrap Script (Ubuntu 24.04)

Автоматический скрипт для **первичной настройки VPS**.  
Ориентирован на **неопытных пользователей**: один запуск, пошаговые вопросы, безопасные значения по умолчанию.

---

## Что делает скрипт

После запуска скрипт **поэтапно**:

- создаёт нового пользователя с правами `sudo`;
- добавляет **публичный SSH-ключ** новому пользователю;
- настраивает SSH:
  - меняет порт;
  - отключает вход под `root`;
  - отключает парольную аутентификацию;
  - включает вход по SSH-ключу;
- **опционально**:
  - включает `UFW` (firewall);
  - устанавливает и настраивает `fail2ban`;
  - устанавливает `Docker`;
  - устанавливает MTProto proxy (через Docker);
  - добавляет полезные **alias** в `.bashrc` нового пользователя;
- выводит итоговое резюме с новыми параметрами доступа;
- пишет лог установки.

---

## Требования

- **Ubuntu 24.04**
- Вы уже подключены к серверу по SSH **под пользователем `root`**
- На сервере есть доступ в интернет
