# VPS Bootstrap Script (Ubuntu 24.04)

Простой установочный скрипт для **первичной настройки VPS**.  
Рассчитан на **неопытного пользователя**.

Скрипт запускается **одной командой**, задаёт понятные вопросы и делает всё автоматически.

---

## Что делает скрипт

После запуска скрипт **по шагам**:

- создаёт нового пользователя с `sudo`
- настраивает SSH:
  - меняет порт
  - отключает вход под `root`
  - отключает вход по паролю
  - включает вход по SSH-ключу
- (опционально) включает `UFW` (firewall)
- (опционально) устанавливает `fail2ban`
- (опционально) устанавливает `Docker`
- (опционально) устанавливает MTProto proxy
- выводит **итоговое резюме** с новыми параметрами подключения

Все действия логируются в файл.

---

## Требования

- Сервер с **Ubuntu 24.04**
- Вы уже подключены к серверу по SSH **под пользователем `root`**
- На сервере есть доступ в интернет
